# SpatialViewer v0.3.3

简体中文 | [日本語](RELEASE-NOTES-v0.3.3.ja.md) | [English](RELEASE-NOTES-v0.3.3.en.md)

## 标签页交互

v0.3.3 聚焦标题栏标签页的桌面端交互补全，不改变现有页面显示效果与整体视觉设计。

- 新建标签页改为类似 Chrome 的横向展开与淡入动画，不再使用会产生纵向闪现感的入口位移动画。
- 标签页动画不进行 Y 轴位移，也不缩放文字或图标，避免打开时出现跳动或模糊。
- 保留现有标签页尺寸、圆角、颜色、选中/非选中状态和相邻标签重排效果。
- CAD 文档标签在悬停后显示图纸预览；主页、项目、收藏、关于图览、设置等应用页面标签不显示悬浮预览。
- CAD 悬停预览使用独立 `Camera2D` 与 Win2D 渲染实例，预览 Fit 不会修改当前图纸的缩放、平移或选择状态。
- CAD 悬停预览承载于独立的 WinUI Mica 窗口，使用真实系统背景材质，而不是透明色模拟。
- 应用页面标签会同步当前页面的名称与符号；在项目、收藏、关于图览或设置页面新建标签时，新标签会继承当前页面，不再自动跳回主页。
- 在多个应用页面标签之间切换时，各标签会恢复自身对应的页面状态。

## 版本与内核

- 产品版本更新为 `0.3.3`，MSIX 包版本为 `0.3.3.0`。
- 发布包继续通过既有发布流程解析并嵌入已完成应用接入的最新稳定 `SpatialViewer.CadCore`。

## 保持不变

v0.3.3 不修改现有标题栏几何尺寸、汉堡菜单、NavigationView、页面背景、浅色/深色主题、项目与收藏页面布局，也不改变 CAD 看图页面现有显示效果。
