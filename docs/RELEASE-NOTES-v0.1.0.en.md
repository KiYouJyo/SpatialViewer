# Spatial Viewer v0.1.0 first preview

- Publishes the first installable Windows preview with a signed MSIXBundle, lightweight one-click installer, and SHA-256 checksum manifest.
- Establishes the Spatial Viewer shell: native Mica title bar, separate rounded tabs, responsive navigation, Light/Dark themes, and persisted theme preference.
- Opens and views DXF/DWG drawings with foundational CAD canvas, layers, selection, properties, and diagnostics.
- Establishes GitHub Release, trilingual release notes, and GitHub Pages homepage infrastructure.

## Current scope

This is a Preview release. GIS, IFC/BIM, and Rhino/3DM are planned but not yet included. See the [CAD compatibility matrix](compatibility/cad.md) for DXF/DWG scope.

## Install

Download `SpatialViewer-v0.1.0-x64-one-click.zip`, fully extract it, then run `① 安装图览.cmd`. The installer downloads the single MSIXBundle from this Release and verifies its SHA-256 checksum and signature before installation.
