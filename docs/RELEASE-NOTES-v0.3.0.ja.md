# SpatialViewer v0.3.0 リリースノート

SpatialViewer v0.3 では、「プロジェクト」と「お気に入り」をプレースホルダーから実際に利用できるローカル整理機能へ接続し、Preview / Stable の製品チャンネル区分を終了します。

## 追加

- **プロジェクト**：新規プロジェクトの作成、複数の図面・空間データの登録、検索、プロジェクトカードからの再オープンに対応しました。
- **フォルダーをインポート**：サイドバーから対象フォルダーを走査し、対応する空間データ拡張子をまとめてフォルダー名のプロジェクトとして登録できます。
- **お気に入り**：よく使うファイルの追加、検索、直接オープン、スター操作による削除に対応しました。
- プロジェクトとお気に入りはユーザーのローカルアプリデータに保存され、ファイル本体はアップロードされません。

## 更新方式

- Preview / Stable の製品チャンネルを廃止し、SpatialViewer 本体は単一のバージョン系列になります。
- GitHub Releases の正式リリースをセマンティックバージョンで比較し、最新正式版より古いすべてのインストール済みバージョンが更新を検出できます。
- `v0.3` の製品バージョンは `0.3.0`、MSIX パッケージバージョンは `0.3.0.0` です。

## UI の扱い

- プロジェクト / お気に入り画面は既存の WinUI 3 テーマリソース、ボタン状態、カード表現を再利用します。
- タイトルバー、ハンバーガーメニュー、NavigationView の外枠、修正済みの背景レイヤーは再設計していません。

## 現在のフォーマット範囲

プロジェクトとお気に入りでは CAD、GIS、IFC、3DM ファイルを整理できます。アプリ内で実際に表示できるのは、現時点では接続済みの DWG / DXF CAD カーネルが中心です。他形式は各独立カーネルの接続に合わせて表示機能を追加します。
