# Spatial Viewer v0.2.2

このリリースは、実際にインストールされた環境で `SpatialViewer.CadCore` の新しいバージョンを検出した後、ダウンロードまたはステージングに失敗する可能性がある問題を集中的に修正します。既に検収済みの Viewer UI レイアウトや操作体系は変更しません。

## CadCore アップデーターの信頼性

- GitHub Release アセットのダウンロードにシステムプロキシ経由の再試行を追加し、プロキシ経路が利用できない場合、不完全な内容を返す場合、または検証に失敗する場合には直接接続へ自動フォールバックします。
- 各ダウンロード試行ごとに GitHub が提供するファイルサイズと SHA-256 を検証し、完全かつハッシュが一致したカーネルパッケージだけを展開・ステージングします。
- `cadcore-release.json`、x64 アーキテクチャ、配布元リポジトリ、SpatialViewer 0.2.x 互換範囲、および 5 個の主要アセンブリのバージョン検証を継続します。
- 更新は引き続き「ステージング → ユーザーがアプリを手動で閉じて再起動 → 新カーネルを有効化」という安全な方式で行い、実行中のアセンブリをホットスワップしません。

## 診断可能な失敗状態

- すべての例外を単一の「カーネル更新失敗」にまとめず、タイムアウト、ネットワーク、SHA-256、ストレージアクセス、パッケージ検証、バージョン不一致などの段階別エラーコードを保持します。
- 詳細はユーザーのカーネルディレクトリ内の `update.log` に記録され、About ページでは短い状態表示を維持しつつツールチップで詳細を確認できます。
- 特定の PC 環境で問題が残った場合も、ダウンロード・検証・ローカルステージングのどこで失敗したかを直接特定できます。

## 検収の強化

- 署名付き検収フローは実際にオンラインの `SpatialViewer.CadCore` Release をダウンロードし、アプリと同じプロキシ再試行 / 直結フォールバック戦略でファイルサイズと SHA-256 を確認します。
- その後、実際にパッケージを展開し、manifest と 5 個の主要 DLL を検証して、`versions/<version>` と `pending.json` のステージング全体をシミュレートします。
- 三言語リソース、Debug/Release、テスト、起動 Smoke、オンライン Release 契約、ランタイムのダウンロード / ステージング、MSIX、署名、オフライン検収パッケージのすべてが成功した場合のみ v0.2.2 の成果物を生成します。

> v0.2.2 は引き続き CadCore v0.2.0 を内蔵フォールバックとして保持するため、独立公開された CadCore v0.2.1 の検出・ダウンロードを実際に検証できます。
