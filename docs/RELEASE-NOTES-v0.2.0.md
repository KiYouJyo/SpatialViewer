# Spatial Viewer v0.2.0 设置与关于页预览版

- 按 Figma《看图》设计稿正式落地“设置”和“关于图览”页面，并保持 WinUI 3 原生控件、材质、主题与动效体系。
- 参考 UrbanPlanToolbox 建立多层卡片的响应式布局：宽屏保持桌面三层 Surface 层级，窄窗口下控件与卡片自适应换行，不压缩为不可用尺寸。
- 设置页新增并持久化应用主题、语言偏好、会话恢复、最近文件、文件变化监视、打开后适合窗口、查看器主题与图纸背景设置。
- “打开文件后适合窗口”现在完全由查看器设置控制；文件外部修改并重新读取时保留当前相机视角。
- 关于页接入 SpatialViewer 与独立 `SpatialViewer.CadCore` 的 GitHub Release 检查，并提供仓库、Releases、许可与隐私等真实入口。
- CAD 内核保持独立仓库与固定 gitlink 集成；GIS、IFC/BIM 与 Rhino 内核入口继续作为明确的未接入状态展示。
- 将应用、程序集、MSIX 与发布元数据统一升级到 0.2.0 / 0.2.0.0，并升级签名验收流水线。

## 当前边界

本版本不改变 v0.1 系列已经验收的 CAD 渲染语义。已知 CAD 颜色映射与圆弧分段问题仍属于 CadCore 后续正确性工作，不在本次 UI/设置/关于页交付中混入修复。

## 安装

优先使用 v0.2.0 Release 提供的签名 MSIXBundle 或离线验收包。离线包包含签名安装包、公开证书、SHA-256 清单与验收说明。
