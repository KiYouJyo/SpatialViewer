# SpatialViewer v0.3.7 起動画面

SpatialViewer v0.3.7 では、UrbanPlanToolbox と PageArc と同じ考え方で Windows ネイティブの起動画面を追加します。

## 主な変更

- コールドスタート時は MSIX の `uap:SplashScreen` を使用し、起動画面のためだけの第2 WinUI ウィンドウは作成しません。
- `#202020` の固定ダーク背景に SpatialViewer の製品アイコンを中央配置し、文字・ボタン・疑似プログレスバーは追加しません。
- 100%、125%、150%、200%、400% の5段階の専用ビットマップを生成し、論理サイズ 620×300 を維持したまま Windows が DPI に応じて最適なリソースを選択します。
- `uap5:Optional="true"` を使用し、高速起動時はシステムが起動画面を省略して直接メインウィンドウへ移行できます。
- 起動リソースの生成と、サイズ・背景色・Manifest の契約検証をビルドゲートへ追加しました。

## 変更しない範囲

- タイトルバー、ハンバーガーメニュー、NavigationView、ページ背景、タブ、CAD 描画、Cad Core の挙動は変更しません。
- メインウィンドウ上に追加のオーバーレイや起動アニメーションを載せず、初回フレームの操作性を維持します。
