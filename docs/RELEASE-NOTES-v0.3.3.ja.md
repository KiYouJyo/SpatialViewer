# SpatialViewer v0.3.3

[简体中文](RELEASE-NOTES-v0.3.3.md) | 日本語 | [English](RELEASE-NOTES-v0.3.3.en.md)

## タブ操作

v0.3.3 はタイトルバーのタブ操作をデスクトップ向けに補完する更新です。既存ページの表示結果や全体のビジュアルデザインは変更しません。

- 新規タブの表示を Chrome に近い横方向の展開＋フェードインへ変更し、縦方向に飛び込むように見える入口移動アニメーションを廃止しました。
- タブ表示時に Y 軸移動や文字・アイコンの拡大縮小を行わず、ちらつきやぼやけを防ぎます。
- 既存のタブ幅、高さ、角丸、色、選択／未選択状態、隣接タブの再配置動作は維持します。
- マウス中ボタンでタブを直接閉じられるようにしました。バックグラウンドのタブを閉じる際に先に選択する必要はありません。
- タブのホバー時にプレビューカードを表示します。CAD ドキュメントのタブでは軽量な図面プレビューを表示できます。
- CAD のホバープレビューは独立した `Camera2D` と Win2D レンダラーを使用するため、プレビューの Fit 操作は現在の図面のズーム、パン、選択状態を変更しません。

## バージョンとカーネル

- 製品バージョンを `0.3.3`、MSIX パッケージバージョンを `0.3.3.0` に更新しました。
- リリースパッケージは従来の公開フローを継続し、アプリ側への統合が完了している最新の安定版 `SpatialViewer.CadCore` を解決して同梱します。

## 変更しない範囲

v0.3.3 では既存タイトルバーのジオメトリ、ハンバーガーメニュー、NavigationView、ページ背景、ライト／ダークテーマ、プロジェクト／お気に入りページのレイアウト、および CAD ビューアの現在の表示結果を変更しません。
