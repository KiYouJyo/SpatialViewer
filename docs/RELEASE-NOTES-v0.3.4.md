# SpatialViewer v0.3.4

简体中文 | [日本語](RELEASE-NOTES-v0.3.4.ja.md) | [English](RELEASE-NOTES-v0.3.4.en.md)

## 自适应标签页

v0.3.4 聚焦标题栏标签页在多文档场景下的可用性，不改变既有页面显示效果与视觉语言。

- 标签页默认仍保持 `220 DIP` 宽度；只有当所有标签页、间距与“+”按钮将超出标题栏可用宽度时才开始压缩。
- 进入拥挤状态后，现有标签页与新标签页会按相同目标宽度均匀收缩，行为接近 Chrome / Firefox。
- 标签页会随着窗口变窄实时压缩，窗口重新变宽或关闭标签页后会自动恢复宽度，最大恢复到原有 `220 DIP`。
- 设置 `72 DIP` 的最小标签宽度；超过这一极限时保留原有水平滚动能力作为兜底，避免无限压缩导致控件不可操作。
- “+”新建标签按钮始终预留独立空间，不会被标签页挤出标题栏。
- 新标签打开时继续沿用 v0.3.3 的横向展开与淡入动画，同时其他标签会先让出空间，不再把新标签推到标题栏可视区域之外。
- 关闭标签页后会在移除完成后重新计算剩余标签宽度并自动展开。

## 版本与内核

- 产品版本更新为 `0.3.4`，MSIX 包版本为 `0.3.4.0`。
- Cad Core 接入与更新机制保持不变。

## 保持不变

v0.3.4 不修改标题栏高度、标签页圆角与颜色、选中/非选中状态、悬停 CAD 预览、汉堡菜单、NavigationView、页面背景、浅色/深色主题以及 CAD 图纸显示效果。
