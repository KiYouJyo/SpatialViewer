# Spatial Viewer v0.2.1 UI 修正・CadCore 独立更新

このバージョンは v0.2.0 の設定ページと情報ページに対する実機確認のフィードバックを反映し、`SpatialViewer.CadCore` の独立更新経路を初めて実装します。本体には常にフォールバック可能な 0.2.0 カーネルを残し、現在の独立 Release である CadCore 0.2.1 をアプリ内で確認・ダウンロードし、ユーザーが図覧を手動で再起動した後に有効化できます。

- NavigationView の不透明なコンテンツ背景を取り除き、Windows Mica をページ下地として再び表示します。
- 設定・情報ページの通常カードを WinUI 3 標準の中立的な Fluent Card / Control Fill リソースへ変更し、青緑色の製品アクセントをカード背景に使わないようにしました。
- UrbanPlanToolbox と同じ考え方のレスポンシブ設定行を採用し、広い画面では操作部を右寄せ、狭い画面では説明文の下へ移動します。
- トグルとコンボボックスは同じ操作列を共有し、広い画面では右端が揃います。
- ビューアー専用テーマ設定を削除し、ビューアーは常にアプリのテーマに従います。図面背景色の設定のみ残します。
- 中国語・日本語・英語の実行時切り替えを接続し、再起動せずに反映し、次回起動時にも保存済み言語を使用します。
- 情報ページはワイド・ミディアム・コンパクトの 3 段階で再配置します。
- ハンバーガーメニューでは「図覧について」を「設定」の上へ移動しました。
- 発行者表示を `Jo Kiyō` に修正しました。
- CAD カーネルはリポジトリ名 `SpatialViewer.CadCore` を明示し、対応する GitHub リポジトリを直接開けます。
- CadCore の状態表示を実際のバージョン確認へ変更し、`未確認 → 確認中 → 最新バージョン / カーネル更新あり` と遷移します。更新がある場合はボタンが「更新をダウンロード」へ変わります。
- カーネルパッケージは GitHub Release からユーザーのローカルデータ領域へ保存し、読み取り専用の MSIX インストール先は変更しません。GitHub SHA-256 に加え、`cadcore-release.json`、x64、配布元リポジトリ、互換範囲、5 個の主要アセンブリのバージョンを検証します。
- ダウンロードと検証が完了すると「更新をダウンロードしました。アプリを再起動すると反映されます」と表示します。実行中のプロセスでは DLL を差し替えず、通常の終了・再起動後、WinUI の作成前に新しいカーネルを読み込みます。
- 本体に同梱されたカーネルは常にフォールバック基準です。将来の Spatial Viewer が外部カーネルと同じか新しい CadCore を同梱した場合は、新しい同梱版を自動的に優先します。

## CadCore 0.2.1

独立した `SpatialViewer.CadCore v0.2.1` はすでに公開され、`CadCore-v0.2.1-x64.zip` と GitHub SHA-256 digest を提供しています。このバージョンには、AutoCAD ACI 1–255、TrueColor / ByLayer / ByBlock の色処理修正と、既定 0.25 px の画面誤差許容値による適応円弧分割が含まれます。

Spatial Viewer v0.2.1 は独立更新を実環境で検証できるよう、意図的に 0.2.0 のフォールバックカーネルを同梱しています。これにより 0.2.1 を実際に検出・ダウンロードし、再起動後に切り替えられます。
