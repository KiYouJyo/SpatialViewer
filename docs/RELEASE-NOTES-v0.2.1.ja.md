# Spatial Viewer v0.2.1 設定・情報ページ修正版

このバージョンは v0.2.0 の設定ページと情報ページに対する実機確認のフィードバックを反映した修正版です。CAD カーネルのバージョンは変更しません。

- NavigationView の不透明なコンテンツ背景を取り除き、Windows Mica をページ下地として再び表示します。
- 設定・情報ページの通常カードを WinUI 3 標準の中立的な Fluent Card / Control Fill リソースへ変更し、青緑色の製品アクセントをカード背景に使わないようにしました。
- UrbanPlanToolbox と同じ考え方のレスポンシブ設定行を採用し、広い画面では操作部を右寄せ、狭い画面では説明文の下へ移動します。
- トグルとコンボボックスは同じ操作列を共有し、広い画面では右端が揃います。
- ビューアー専用テーマ設定を削除し、ビューアーは常にアプリのテーマに従います。図面背景色の設定のみ残します。
- 中国語・日本語・英語の実行時切り替えを接続し、再起動せずに反映し、次回起動時にも保存済み言語を使用します。
- 情報ページはワイド・ミディアム・コンパクトの 3 段階で再配置します。
- ハンバーガーメニューでは「図覧について」を「設定」の上へ移動しました。
- 発行者表示を `Jo Kiyō` に修正しました。
- CAD カーネルはリポジトリ名 `SpatialViewer.CadCore` を明示し、対応する GitHub リポジトリを直接開けます。

## 現在の範囲

CAD の完全な ACI カラー解決と円弧の折れ線化解消は引き続き `SpatialViewer.CadCore` 側の独立したカーネル正確性タスクです。
