# Spatial Viewer v0.2.0 設定・About プレビュー

- Figma「看图」の設計に合わせて「設定」と「図覧について」を正式実装し、WinUI 3 のネイティブコントロール、マテリアル、テーマ、アニメーションを維持しました。
- UrbanPlanToolbox を基準に多層カードのレスポンシブレイアウトを導入しました。広いウィンドウではデスクトップ向けの Surface 階層を維持し、狭いウィンドウではコントロールとカードが自然に折り返します。
- アプリテーマ、言語設定、前回セッションの復元、最近使ったファイル、外部ファイル変更監視、オープン時の全体表示、ビューアテーマ、図面背景を保存できるようにしました。
- 「オープン時にウィンドウへ合わせる」はビューア設定だけで制御されるようになり、外部変更による再読込時には現在のカメラ位置を保持します。
- About ページから SpatialViewer と独立した `SpatialViewer.CadCore` の GitHub Release を確認でき、リポジトリ、Releases、ライセンス、プライバシーへ実際に移動できます。
- CAD コアは独立リポジトリと固定 gitlink の構成を維持します。GIS、IFC/BIM、Rhino のコアは未接続であることを明示しています。
- アプリ、アセンブリ、MSIX、リリースメタデータを 0.2.0 / 0.2.0.0 に統一し、署名付き受け入れテストのパイプラインも更新しました。

## 現在の範囲

このリリースでは v0.1 系で受け入れ済みの CAD 描画仕様は変更しません。既知の CAD 色マッピングと円弧の分割表示は CadCore 側の後続タスクです。

## インストール

v0.2.0 Release の署名済み MSIXBundle、またはオフライン受け入れパッケージを使用してください。オフラインパッケージには署名済みインストーラー、公開証明書、SHA-256 一覧、受け入れ結果が含まれます。
