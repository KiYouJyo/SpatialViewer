# Spatial Viewer v0.1.0 最初のプレビュー

- 署名済み MSIXBundle、軽量ワンクリック インストーラー、SHA-256 チェックサムを含む最初の Windows プレビューを公開します。
- ネイティブ Mica タイトルバー、独立した角丸タブ、レスポンシブ ナビゲーション、ライト/ダーク テーマとテーマ記憶を実装しました。
- DXF/DWG 図面を開いて表示でき、CAD キャンバス、レイヤー、選択、プロパティ、診断の基礎機能を提供します。
- GitHub Release、3 言語のリリース ノート、GitHub Pages の基盤を整備しました。

## 現在の範囲

これは Preview 版です。GIS、IFC/BIM、Rhino/3DM は今後の予定です。DXF/DWG の対応範囲は [CAD compatibility matrix](compatibility/cad.md) を参照してください。

## インストール

`SpatialViewer-v0.1.0-x64-one-click.zip` をダウンロードし、完全に展開してから「① 安装图览.cmd」を実行してください。インストーラーはこの Release から唯一の MSIXBundle を取得し、SHA-256 と署名を検証してからインストールします。
