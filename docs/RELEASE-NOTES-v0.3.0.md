# SpatialViewer v0.3.0 发行说明

SpatialViewer v0.3 将「项目」与「收藏」从占位入口接入为可实际使用的本地资料组织功能，并结束 Preview / 预览版发布通道的区分。

## 新增

- **项目**：可以新建项目、一次选择多份图纸/空间数据、按项目搜索，并从项目卡片重新打开其中的文件。
- **导入文件夹**：侧栏“导入文件夹”会扫描支持的空间数据扩展名，并以文件夹名称建立项目。
- **收藏**：可以选择常用文件加入收藏、搜索收藏、直接打开，或通过星标按钮移除收藏。
- 项目与收藏均持久化到用户本地应用数据目录，不上传文件内容。

## 更新机制

- 取消 Preview / Stable 的产品通道区分，SpatialViewer 主程序只保留一条版本线。
- 主程序按语义版本号比较 GitHub Releases；任何低于最新正式版本的已安装版本都可以发现更新。
- `v0.3` 的产品版本为 `0.3.0`，MSIX 包版本为 `0.3.0.0`。

## 界面约束

- 项目与收藏页面复用现有 WinUI 3 主题资源、按钮状态和卡片语言。
- 本版本不重新设计标题栏、汉堡菜单、NavigationView 外壳或已修复的页面背景层级。

## 当前格式边界

项目与收藏可以整理 CAD、GIS、IFC 与 3DM 文件；当前应用内实际查看仍以已接入的 DWG / DXF CAD 内核为准。其他格式会在对应独立内核接入后逐步获得查看能力。
