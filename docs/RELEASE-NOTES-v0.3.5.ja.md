# SpatialViewer v0.3.5

[简体中文](RELEASE-NOTES-v0.3.5.md) | 日本語 | [English](RELEASE-NOTES-v0.3.5.en.md)

## CAD レイヤーの並び順

v0.3.5 では、CAD レイヤーパネルがファイルの解析順／出現順をそのまま使用していた問題を修正し、CAD に近い先頭文字の昇順でレイヤー名を表示します。

- 数字で始まるレイヤーを最初に配置し、`0` → `9` の順で並べます。
- 次に英字で始まるレイヤーを、大文字・小文字を区別せず `A` → `Z` の順で並べます。
- その後に漢字で始まるレイヤーを、簡体字中国語のピンイン照合順で並べ、先頭文字の読みが `A` → `Z` になるようにします。
- その他の記号で始まる名前と空の名前は上記 3 グループの後ろに配置し、一般的な CAD レイヤー順を乱さないようにします。
- 並べ替えはレイヤー一覧の表示順だけを変更します。レイヤーオブジェクト自体は複製・置換しないため、表示／非表示、選択オブジェクトとのレイヤー連動、色、線種、CAD レンダリングは変わりません。
- ファイルの自動再読み込み後も同じ並べ替え規則を再適用します。

## バージョンとカーネル

- 製品バージョンを `0.3.5`、MSIX パッケージバージョンを `0.3.5.0` に更新しました。
- Cad Core の統合・更新方式は変更していません。

## 変更しない範囲

v0.3.5 では CAD 図面の解析順・描画順、タイトルバー、タブ、ハンバーガーメニュー、NavigationView、ページ背景、ライト／ダークテーマ、および既存の CAD 表示結果を変更しません。
