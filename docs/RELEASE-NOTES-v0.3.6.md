# SpatialViewer v0.3.6

简体中文 | [日本語](RELEASE-NOTES-v0.3.6.ja.md) | [English](RELEASE-NOTES-v0.3.6.en.md)

## 全新应用图标

v0.3.6 使用已选定的低饱和规划设计风图标作为 SpatialViewer 的正式产品标识。图标以四象限图纸结合放大镜为核心，同时保留 CAD 平面、GIS 地图、Rhino 曲面与 BIM 建筑体块四类意象，图标外缘保持透明。

- 更新开始菜单与 Windows 应用包使用的 `Square150x150Logo`、`Square44x44Logo` 与 `StoreLogo`。
- 为任务栏/固定图标使用场景补充无底板的小尺寸图标资源，并在可执行文件中嵌入 Windows 图标作为窗口与未打包运行时的回退。
- 自定义标题栏左侧加入同一产品图标，不改变既有标题栏高度、标签页区域及窗口控制按钮。
- 关于页面的原占位符替换为正式产品图标，既有信息布局与响应式行为不变。
- 启动画面同步使用新的低饱和浅色背景与产品标识。

## 版本

- 产品版本：`0.3.6`
- MSIX 包版本：`0.3.6.0`
- Cad Core 接入版本与更新机制保持不变。

## 保持不变

本次为品牌资源更新，不修改 CAD 解析/渲染、标签页交互、NavigationView、页面背景、浅色/深色主题、项目与收藏数据以及 Cad Core 更新逻辑。
