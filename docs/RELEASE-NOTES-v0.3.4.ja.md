# SpatialViewer v0.3.4

[简体中文](RELEASE-NOTES-v0.3.4.md) | 日本語 | [English](RELEASE-NOTES-v0.3.4.en.md)

## アダプティブタブ

v0.3.4 は、多数のドキュメントを開いたときのタイトルバー上のタブ操作性を改善します。既存のページ表示やビジュアル言語は変更しません。

- 通常時のタブ幅は従来どおり `220 DIP` を維持し、全タブ・間隔・「+」ボタンがタイトルバーの利用可能幅を超える場合だけ圧縮を開始します。
- 混雑時は、既存タブと新しいタブを同じ目標幅へ均等に縮小し、Chrome / Firefox に近い挙動にします。
- ウィンドウを狭くするとリアルタイムで縮小し、広げ直した場合やタブを閉じた場合は最大 `220 DIP` まで自動的に戻ります。
- 最小タブ幅は `72 DIP` とし、それ以上のタブ数では既存の水平スクロールをフォールバックとして残します。
- 「+」新規タブボタン用の領域は常に確保され、タブに押し出されません。
- v0.3.3 の横方向展開＋フェードインアニメーションはそのまま維持し、新しいタブを開く前に既存タブが必要な空間を譲ります。
- タブを閉じた後は、削除完了後に残りのタブ幅を再計算して自動的に広げます。

## バージョンとカーネル

- 製品バージョンを `0.3.4`、MSIX パッケージバージョンを `0.3.4.0` に更新しました。
- Cad Core の統合および更新方式は変更しません。

## 変更しない項目

v0.3.4 では、タイトルバーの高さ、タブの角丸・色・選択状態、CAD ホバープレビュー、ハンバーガーメニュー、NavigationView、ページ背景、ライト／ダークテーマ、CAD 図面の表示結果を変更しません。
