# Spatial Viewer v0.2.7

v0.2.7 では、ライト / ダークテーマにおけるコンテンツ領域の背景表示不具合を修正し、正式 Release に同梱するカーネルの選定ルールを自動化しました。タイトルバー、タブバー、ハンバーガーメニュー、ナビゲーションペイン、および既存レイアウトは今回の視覚修正の対象外です。

## ライト / ダークテーマの修正

- ライトテーマの Brush が静的にダークテーマへ残る原因となっていたコンテンツ背景の上書きを削除し、WinUI `NavigationView` の標準テーマリソースに背景管理を戻しました。
- ライトモードの通常時 / 操作時のページ表示を修正すると同時に、ダークモードでページ全体に半透明の白いレイヤーが掛かる問題を解消しました。
- テーマ切り替えは動的テーマリソースを利用し、ライト、ダーク、システム連動の切り替え後に以前のページ背景色が残らないようにしました。

## Release のカーネル同梱ポリシー

- 本バージョン以降、正式 Release は「アプリ側の機能接続が完了済み」の各カーネルについて、公開時点の最新安定版を自動解決して同梱します。接続未完了のカーネルはパッケージに含めません。
- 現在、機能接続が完了しているのは CAD のみのため、v0.2.7 には最新安定版 `SpatialViewer.CadCore v0.4.0` のみを同梱します。
- 公開フローでは CadCore Release のリポジトリ、x64 ランタイム、`SpatialViewer 0.2.x` 互換範囲、ABI `1.0.0.0`、公開ダイジェスト、5 個の主要アセンブリを検証し、検証済みの公式 Release バイナリを `Kernels/Bundled/0.4.0/` に配置します。
- パッケージ内の同梱カーネルはオンライン Release から取得したファイルと SHA-256 を個別比較し、ソースサブモジュール内の古いビルドや誤ったバージョンが正式版へ混入することを防ぎます。

## 検収

- 3 言語リソース、Debug / Release x64 ビルド、Release テスト、DebugHost 起動 Smoke をすべて通過しました。
- CadCore のオンライン更新、ABI、ダウンロード / ステージング、再起動後の有効化フローを検証済みです。
- 0.2.7.0 MSIXBundle のカーネル分離レイアウト、最新 CadCore の注入、デジタル署名、ワンクリックインストーラを Release フロー内で再検証します。

> アプリのバージョンは `0.2.7`、MSIX パッケージバージョンは `0.2.7.0` です。正式パッケージには `SpatialViewer.CadCore v0.4.0`（ABI `1.0.0.0`）を同梱します。
