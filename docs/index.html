面向 CAD、GIS、BIM/IFC 与 Rhino 数据的现代 Windows 看图器。先把文件打开、看准、看顺，再逐步把不同空间数据类型收进同一个原生桌面体验。

CAD、GIS、BIM/IFC、Rhino データを一つのモダンな Windows ビューアで扱うことを目指しています。まずは正確で快適な閲覧を優先し、各種空間データを段階的に統合します。

A modern Windows viewer for CAD, GIS, BIM/IFC, and Rhino data. The priority is fast, faithful viewing first, with more spatial-data kernels integrated into one native desktop experience over time.

一个看图器，统一查看体验一つのビューア、統一された操作One viewer, one viewing experience

沿用 WinUI 3 原生交互，把文件浏览、标签页、图层、对象信息和项目收藏组织成一致的桌面工作流。

WinUI 3 のネイティブ操作を基礎に、ファイル、タブ、レイヤー、オブジェクト情報、プロジェクトを一貫したワークフローにまとめます。

A native WinUI 3 workflow that keeps files, tabs, layers, object information, projects and favorites consistent across formats.

01

原生 Windows 界面ネイティブ Windows UINative Windows UI

WinUI 3、Mica、系统主题与高 DPI 适配，遵循 Windows 自身的交互习惯。

WinUI 3、Mica、システムテーマ、高 DPI に対応します。

WinUI 3, Mica, system themes and high-DPI behavior built around Windows conventions.

02

多标签查看マルチタブ表示Multi-tab viewing

用接近浏览器的标签页同时打开多份图纸，并支持压缩、预览与中键关闭。

ブラウザーに近いタブ操作で複数図面を同時に扱えます。

Browser-like tabs for multiple drawings, including compression, preview and middle-click close.

03

图层与对象信息レイヤーとオブジェクト情報Layers and object data

围绕查看任务提供图层、选择和属性信息，而不是把界面堆成完整编辑器。

閲覧に必要なレイヤー・選択・属性情報を中心にします。

Layer, selection and property information focused on viewing instead of recreating a full editor.

04

项目与收藏プロジェクトとお気に入りProjects and favorites

よく使う図面とプロジェクトをまとめます。

Keep frequently used drawings and project context close at hand.
