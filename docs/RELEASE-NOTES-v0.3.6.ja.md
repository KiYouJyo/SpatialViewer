# SpatialViewer v0.3.6

[简体中文](RELEASE-NOTES-v0.3.6.md) | 日本語 | [English](RELEASE-NOTES-v0.3.6.en.md)

## 新しいアプリアイコン

v0.3.6 では、選定済みの低彩度・都市／建築デザイン系アイコンを SpatialViewer の正式なプロダクトアイコンとして採用しました。4 分割された図面と中央のルーペを基調に、CAD 平面図、GIS マップ、Rhino 曲面、BIM 建築ボリュームの要素を残し、アイコン外側は透明です。

- スタートメニューと Windows パッケージで使用する `Square150x150Logo`、`Square44x44Logo`、`StoreLogo` を更新しました。
- タスクバー／ピン留め表示向けの小サイズ・アンプレート資産を補い、未パッケージ実行時やウィンドウ表示のフォールバックとして Windows 実行ファイルにもアイコンを埋め込みます。
- 既存のタイトルバー高さ、タブ領域、ウィンドウボタンを変更せず、カスタムタイトルバー左側に同じプロダクトアイコンを表示します。
- About ページのプレースホルダー記号を正式アイコンへ置き換え、既存の情報レイアウトとレスポンシブ動作は維持します。
- スプラッシュ画面も新しい低彩度の明るい背景とプロダクトマークへ統一します。

## バージョン

- プロダクトバージョン: `0.3.6`
- MSIX パッケージバージョン: `0.3.6.0`
- Cad Core の統合バージョンと更新方式は変更しません。

## 変更しない項目

本リリースはブランド資産のみの更新です。CAD の解析／描画、タブ操作、NavigationView、ページ背景、ライト／ダークテーマ、Projects／Favorites データ、Cad Core 更新ロジックは変更しません。
