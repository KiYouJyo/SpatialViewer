# SpatialViewer v0.3.5

简体中文 | [日本語](RELEASE-NOTES-v0.3.5.ja.md) | [English](RELEASE-NOTES-v0.3.5.en.md)

## CAD 图层排序

v0.3.5 修正 CAD 图层面板沿用文件解析/出现顺序的问题，使图层名称按更接近 CAD 的首字母升序显示。

- 数字开头的图层优先，按 `0` → `9` 排序。
- 之后是英文字母开头的图层，忽略大小写按 `A` → `Z` 排序。
- 再之后是汉字开头的图层，使用简体中文拼音排序，使首字拼音按 `A` → `Z` 排列。
- 其他符号开头以及空名称移动到上述三类之后，避免打乱常用 CAD 图层顺序。
- 排序只改变图层列表的显示顺序，不复制或替换图层对象，因此图层可见性开关、对象选中时的图层联动、颜色、线型以及 CAD 渲染保持不变。
- 文件自动重载后会重新应用同一排序规则。

## 版本与内核

- 产品版本更新为 `0.3.5`，MSIX 包版本为 `0.3.5.0`。
- Cad Core 接入与更新机制保持不变。

## 保持不变

v0.3.5 不修改 CAD 图纸解析与绘制顺序、标题栏、标签页、汉堡菜单、NavigationView、页面背景、浅色/深色主题以及既有 CAD 显示效果。
