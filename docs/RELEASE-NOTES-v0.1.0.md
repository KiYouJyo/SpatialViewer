# Spatial Viewer v0.1.0 首个预览版

- 发布首个可安装的 Windows 预览版，提供签名 MSIXBundle、轻量一键安装器和 SHA-256 校验清单。
- 建立图览产品壳：原生 Mica 标题栏、圆角独立标签页、响应式导航、深浅色主题与主题记忆。
- 支持打开并查看 DXF/DWG 图纸，包含 CAD 画布、图层、对象选择、属性与诊断基础能力。
- 建立 GitHub Release、三语发布说明和 GitHub Pages 首页基础设施。

## 当前边界

这是 Preview 版本。GIS、IFC/BIM 与 Rhino/3DM 仍处于规划阶段；DXF/DWG 支持范围请参阅 [CAD 兼容矩阵](compatibility/cad.md)。

## 安装

优先下载 `SpatialViewer-v0.1.0-x64-one-click.zip`，完整解压后运行“① 安装图览.cmd”。安装器会从本 Release 下载唯一的 MSIXBundle，验证 SHA-256 与签名后再安装。
